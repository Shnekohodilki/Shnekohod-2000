# Расчёт и подбор драйверов двигателей

## 1. Общая информация

В проекте рассматривается применение двух типов электродвигателей:
- DC-двигатели.
- Шаговые двигатели.

Для каждого типа двигателя предусматривается отдельная схема управления, соответствующая электрическим характеристикам двигателя.

## 2. DC-двигатели

Для управления DC-двигателями рассматривается использование драйвера DRV8833.

DRV8833 предназначен для управления двигателями постоянного тока и позволяет управлять направлением вращения и скоростью двигателя посредством ШИМ.

Предполагаемая конфигурация:
- Один модуль DRV8833 для управления двумя DC-двигателями.
- Управление осуществляется посредством сигналов от ESP32.
- Скорость регулируется с помощью PWM (ШИМ).
- Направление вращения определяется управляющими сигналами.

Окончательная применимость DRV8833 определяется током двигателей, особенно током при остановке (stall current), и условиями эксплуатации.

## 3. Шаговые двигатели

В проекте рассматриваются два шаговых двигателя NEMA 17.

Для их управления требуется соответствующий драйвер шагового двигателя. Подбор драйвера должен учитывать:
- Номинальный ток двигателя.
- Возможность регулировки тока.
- Напряжение питания.
- Нагрев драйвера.
- Требуемую точность управления.

DRV8833 рассматривается для DC-двигателей. Его не следует автоматически считать подходящим драйвером для выбранных шаговых двигателей без проверки совместимости и электрических параметров.

## 4. Предварительные требования к системе

- Обеспечение независимого управления двигателями.
- Возможность изменения скорости.
- Возможность изменения направления движения.
- Защита драйверов от перегрузок.
- Поддержание стабильного питания управляющей электроники.
