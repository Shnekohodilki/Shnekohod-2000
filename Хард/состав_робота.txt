# Аппаратная часть робота

## 1. Общая структура

Аппаратная часть робота состоит из управляющей электроники, электродвигателей, датчиков, камеры, силовой части и системы питания.

Основной управляющий элемент системы — микроконтроллер ESP32.

## 2. Основные компоненты

### 2.1. ESP32
Используется в качестве основной управляющей платы системы.

Основные функции:
- Управление исполнительными механизмами.
- Обработка данных датчиков.
- Обмен данными с другими устройствами.
- Использование Wi-Fi и Bluetooth при необходимости.
- Реализация управляющей логики.

### 2.2. Шаговые двигатели NEMA 17
Количество: 2 шт.

Предназначены для выполнения перемещений и позиционирования в механической системе робота.

Предусматривается отдельное управление каждым двигателем посредством драйверов шаговых двигателей.

### 2.3. DC-двигатели
Используются в исполнительной системе робота.

Управление осуществляется посредством драйвера DRV8833, рассматриваемого для управления двумя DC-двигателями через один модуль.

### 2.4. Драйвер DRV8833
Предназначен для управления DC-двигателями.

Функции:
- Управление направлением вращения.
- Регулирование скорости посредством ШИМ.
- Управление двумя DC-двигателями при использовании одного модуля.

### 2.5. Драйверы шаговых двигателей
Используются для управления двумя шаговыми двигателями NEMA 17.

Подбор драйверов осуществляется с учётом токовых характеристик двигателей и необходимого режима работы.

### 2.6. Гироскоп и акселерометр MPU6050
Используется для измерения ускорения и угловой скорости.

Предназначен для получения данных о движении и ориентации устройства.

### 2.7. Камера
Камера предусматривается в составе системы для получения визуальной информации.

Конкретная модель камеры, способ подключения, требования к питанию и интерфейс передачи данных должны быть уточнены.

### 2.8. DC-DC преобразователь
Используется для понижения напряжения с 12 В до 5 В.

Предназначен для питания компонентов, которым требуется напряжение 5 В.

## 3. Система питания

Основной источник питания системы — 12 В.

От него осуществляется питание силовой части, включая двигатели, а также DC-DC преобразователя для получения 5 В.

Питание электронных компонентов организуется с учётом требуемого напряжения каждого устройства.

## 4. Предварительная структура соединений

- Источник питания 12 В — основная силовая линия.
- DC-двигатели — подключаются через драйвер DRV8833.
- Шаговые двигатели — подключаются через соответствующие драйверы.
- ESP32 — управляющий микроконтроллер.
- MPU6050 — подключается к ESP32.
- Камера — подключается к предусмотренному интерфейсу управляющей системы.
- DC-DC преобразователь — обеспечивает получение напряжения 5 В.

## 6. Примечание

Аппаратная конфигурация является предварительной. Окончательная схема подключения, выбор драйверов, источника питания и интерфейсов осуществляется после уточнения характеристик всех комплектующих.
