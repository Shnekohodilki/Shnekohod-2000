# Драйверы двигателей Shnekohod-2000

## 1. Назначение

Драйверы предназначены для управления электродвигателями роботизированной платформы, обеспечивая изменение направления вращения, управление скоростью и остановку приводов.

## 2. Предварительная конфигурация

Рассматривается система с двумя независимыми шнековыми приводами.

В зависимости от окончательного выбора двигателей может потребоваться:

- два отдельных драйвера;
- один многоканальный модуль;
- отдельные драйверы для каждого двигателя.

Конфигурация определяется типом двигателя, током, напряжением, режимом работы и требованиями к управлению.

## 3. DRV8833

DRV8833 рассматривается как потенциальный вариант драйвера для двигателей постоянного тока.

### Основные функции

- Управление двигателями постоянного тока.
- Изменение направления вращения.
- Управление скоростью посредством PWM.
- Управление двумя каналами в рамках одного модуля.

### Возможное применение

В случае использования двух двигателей постоянного тока один двухканальный модуль может использоваться для управления двумя двигателями, если параметры двигателей соответствуют допустимым параметрам драйвера.

### Ограничения

DRV8833 необходимо оценивать с учётом:

- рабочего тока двигателя;
- пикового тока;
- теплового режима;
- напряжения питания;
- режима длительной работы;
- нагрузки при заклинивании.

Для высоконагруженных шнековых приводов допустимость применения DRV8833 должна быть подтверждена расчётами и испытаниями.

## 4. Шаговые двигатели

Ранее рассматривались шаговые двигатели формата NEMA 17.

Для управления шаговыми двигателями необходимо использовать драйверы, соответствующие выбранному типу двигателя.

DRV8833 не рассматривается как стандартный специализированный драйвер для управления шаговыми двигателями NEMA 17 в предполагаемой конфигурации.

При выборе драйвера шагового двигателя необходимо учитывать:

- ток фаз;
- напряжение;
- требуемый крутящий момент;
- режим микрошагов;
- нагрев;
- режим длительной работы.

## 5. Предварительные варианты

В зависимости от окончательной конфигурации приводов рассматриваются:

- DRV8833 — для подходящих двигателей постоянного тока;
- специализированные драйверы шаговых двигателей — для NEMA 17 или других шаговых двигателей.

## 6. Статус

Окончательный выбор драйверов не утверждён.

Необходимо подтвердить тип двигателей, требуемый ток, режим нагрузки и допустимый тепловой режим.
